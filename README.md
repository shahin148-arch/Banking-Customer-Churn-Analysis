# Banking Customer Churn Analysis

## Project Overview
This project analyzes banking customer data to identify factors associated with customer churn and explore machine learning approaches for churn prediction.

## Objectives
- Explore customer data using Exploratory Data Analysis (EDA).
- Identify factors associated with customer churn.
- Build classification models using Logistic Regression and Random Forest.
- Evaluate model predictions using a confusion matrix.
- Derive insights that may support customer retention strategies.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and preprocessing
2. Exploratory Data Analysis
3. Feature analysis
4. Model training
5. Model evaluation
6. Business insights and conclusion

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Run the cells in order.
